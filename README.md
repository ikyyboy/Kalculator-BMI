
# 🧮 Kalkulator BMI

Aplikasi desktop sederhana untuk menghitung **Body Mass Index (BMI)** menggunakan JavaFX.

## 🛠️ Teknologi
- Java
- JavaFX
- FXML
- Scene Builder
- Apache NetBeans
- Maven

## ✨ Fitur
- Input berat badan (kg).
- Input tinggi badan (cm).
- Menghitung nilai BMI.
- Menampilkan kategori BMI.

## 📐 Rumus BMI
BMI = Berat Badan (kg) / Tinggi Badan (m)²
